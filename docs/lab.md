# Try the Hound

Tap the screen to explore. Choose a dog, send a sample scent, or preview the red Travel Watch warning. Everything runs in this browser tab with synthetic sightings and temporary progress.

[Open the full-window lab](lab-app/index.html){ .md-button .md-button--primary target="_blank" rel="noopener" }
[Lab guide and controls](simulator.md){ .md-button }

<iframe class="hound-lab-frame" src="lab-app/index.html" title="Interactive Surveillance Hound browser lab" loading="lazy"></iframe>

Requires a current browser with JavaScript and WebAssembly. Reloading starts a fresh session. The lab does not scan nearby Wi-Fi/Bluetooth, connect to hardware, or save progress. If the frame cannot load, use the full-window link above or the [native local setup](simulator.md#run-the-native-local-lab).
